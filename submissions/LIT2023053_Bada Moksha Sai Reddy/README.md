# Data Mining Assignment: Data Lake Preprocessing

## Dataset Name
`sales.csv`

## How to Run the Notebook
1. Open Google Colab (https://colab.research.google.com/).
2. Upload the `Data_Lake_Assignment.ipynb` notebook.
3. Once opened, expand the left sidebar and click on the **Files** icon (folder).
4. Run the first code cell to create the `data_lake/bronze` and `data_lake/silver/preprocessed_sales` folders.
5. Upload your `sales.csv` file into the `data_lake/bronze/` folder inside Colab.
6. Run the remaining cells from top to bottom.

## Data Lake Structure
The assignment implements a simplified Data Lake architecture:
- **Bronze Layer (`data_lake/bronze/`)**: Stores the raw, unmodified `sales.csv` dataset.
- **Silver Layer (`data_lake/silver/preprocessed_sales/`)**: Stores the cleaned and transformed dataset generated by Apache Spark, saved in CSV format.

## Preprocessing Summary
The following basic transformations were performed using PySpark:
1. **Duplicates**: Dropped exact duplicate rows using `dropDuplicates()`.
2. **Text Standardization**: Standardized capitalization using `initcap()` and removed trailing/leading spaces using `trim()` on all string columns.
3. **Missing/Invalid Numerical Values**: Identified negative quantities/prices and reset them to 0. Bounded discounts between 0 and 100. Null numerical values were filled with 0.
4. **Dates**: Converted valid date strings into standard DateType format using `to_date()`.
